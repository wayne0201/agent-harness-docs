深入浅出 AI Agent

以 DeepSeek Harness 为例，沿「哲学 → 科学 → 艺术」三篇，先学会用好 Agent，再造出 Agent

哲学 → 科学 → 艺术 一切皆插件 事件驱动 能力接缝 从需求到反馈的闭环

这不是一本「介绍某个框架 API」的手册，而是一本教你像 Agent 工程师一样思考与做事的书。我们解剖一个真实、自洽的开源 Agent 框架——DeepSeek Harness，沿着「哲学 → 科学 → 艺术」的路径，从「为什么」走到「怎么做」，再走到「怎么做好」。

三种读法

01
系统通读

从第一篇到第三篇，按顺序建立完整的认知体系，适合想成为全链路工程师的你。

02
边读边做

每章末尾都有「动手做」。跟着第 8–12 章上手使用，跟着第 13–18 章拆源码，跟着第 19–25 章做项目。

03
按需查阅

第 17 章查「接缝」，第 22 章查「调试」，附录查术语。把本书当作工作台。

▶从哪儿开始

第一次读，建议先花 3 分钟读前言，再进入哲学篇；着急动手的，可以直接跳第 7 章或附录 B。
